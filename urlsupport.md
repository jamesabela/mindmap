URL Import Support

Importing data via URL parameters, making it easy for AI agents or scripts to generate links.

Supported Parameters:

title: Sets the central topic.
nodes: Sets the node text (must be URL encoded).
nodes_b64: Sets the node text using Base64 encoding (safer for complex content).
Example URL:

exportmm.html?title=My%20Map&nodes=%F0%9F%92%A1%20Idea%201%0A%09Sub-idea
